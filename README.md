# Typing Speed Test — Vanilla JavaScript

A small browser-based typing exercise built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in your browser. No package manager or build step is required.

## Project files

- `index.html` — page structure
- `main.css` — styles
- `main1.js` — client-side behavior

## Purpose

An introductory front-end project demonstrating DOM interactions, event handling, and browser UI development.

## Status

Educational mini-project. It is preserved as part of my early development work, not presented as a production application.
